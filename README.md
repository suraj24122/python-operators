📘 Python Beginner Programs – Operators & Conditionals
This repository contains 10 beginner-level Python programs focused on:

Arithmetic Operators

Comparison Operators

Logical Conditions

User Input

Simple Real-world Calculations

Perfect for students and beginners learning Core Python Fundamentals!

📁 Contents
File Name	Topic	Description
program_1.py	Arithmetic Operators	Perform +, -, *, /, % on two numbers
program_2.py	Exponent Operator	Calculate square and cube using **
program_3.py	Average	Find average of three numbers
Program_4.py	Time Conversion	Convert minutes into hours and minutes
program_5.py	Modulus	Remainder when a number is divided by 7
program_6.py	Equality Check	Check if two numbers are equal
program_7.py	Age Check	Check if user is eligible to drive
program_8.py	Greatest Number	Compare three numbers and print the greatest
program_9.py	Logical Condition	Check if a number is divisible by both 3 and 5
program_10.py	License Eligibility	Check driving license eligibility (age + eye test)

🛠️ Requirements
Python 3.x

IDE or terminal with Python installed

🚀 How to Run
Clone the repository or download the .py files.

Open each file in VS Code / Thonny / PyCharm / IDLE.

Run the file and follow the input prompts.

python program_1.py
📚 Learning Outcomes
Variables and data types

Arithmetic & comparison operators

User input handling

Conditional statements (if, else)

Basic Python syntax and structure
